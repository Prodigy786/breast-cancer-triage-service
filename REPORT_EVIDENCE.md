### Task 18: Written Analysis (Strictly $\le$ 150 Words)

**1. Image vs. Container & Image Deletion:**  
An image is an immutable, read-only template (filesystem layers + metadata), whereas a container is a stateful, running instance with a writable overlay layer. Deletion fails because the container's writable layer actively depends on the underlying image layer IDs; removing the base image would corrupt the container's filesystem.

**2. Network Listening & Port Mapping:**  
Listening on `0.0.0.0` binds the server to all network interfaces, including the container's virtual bridge interface (`eth0`). Listening on `127.0.0.1` restricts access strictly inside the container namespace. Host port mapping (`host_port:container_port`) configures kernel NAT/iptables rules to forward external host traffic into the isolated container port.

**3. DVC Pointer vs. Data Restoration:**  
Git tracks lightweight `.dvc` text pointers (MD5 hashes) to avoid repository bloat and bandwidth saturation from large binary files. To restore data on a new machine, you need access to the configured storage remote (`dvc-remote/`) and run `dvc pull`.
